# Everything seems to work, but it always uses an external preview tool

_Note that this should never occur when using a prebuilt kit from the
[release page](https://github.com/ChordPro/chordpro/releases)._

This is most likely a problem with your linux installation. Some
distro's ship with an incomplete set of wxWidgets libraries.

See
[here]({{< relref
"chordpro-install-on-debian/#installation-on-debian-stable-and-lts" >}})
for more details.
